Machine learning · Python

ShopSphere Customer Analytics

Churn prediction, lifetime value forecasting and customer segmentation for a fictional online retailer, on 50,000 customer records, following the CRISP-DM process.

  • Compared 6 classifiers with class weighting, cross-validated tuning and threshold optimisation. Random Forest and a neural network tied as best.
  • Forecast customer lifetime value with Gradient Boosting after comparing 6 regression models.
  • Segmented customers with 5 clustering methods, including an autoencoder, and flagged a 100-customer group with an 89% return rate for review.
  • Found and fixed a data-entry error in 25 order values (about 100× too large), which cut that column's skewness from 42 to under 1.

Data analytics · Power BI

ShopWave Customer Behaviour Dashboard

A full ETL pipeline and interactive dashboard for a fictional US e-commerce company whose customer data had piled up quality problems.

  • Cleaned a deliberately messy 890-record dataset in Power Query, fixing 6 kinds of issues: inconsistent labels, missing values, duplicates, negative spend, misspelt cities and out-of-range ratings. 854 reliable records remained.
  • Designed a star-schema model with 1 fact table and 4 dimension tables, using surrogate keys and one-to-many relationships.
  • Built a 4-page dashboard with slicers, 9 DAX measures, a decomposition tree and a shape map to show at-risk and unsatisfied customers.
